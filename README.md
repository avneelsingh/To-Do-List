# 📝 To-Do List

A simple and modern **To-Do List web application** built using **React.js**.  
The application allows users to create, complete, delete, and reorder tasks using drag-and-drop. Todo data is automatically saved in the browser's **Local Storage**, so tasks remain available even after refreshing the page.

## 🚀 Features

- ➕ Add new tasks
- ✅ Mark tasks as completed
- ❌ Delete tasks
- 🔄 Drag and drop tasks to change their order
- 💾 Persistent data using Local Storage
- 🎨 Clean and responsive user interface
- 📱 Responsive design for different screen sizes
- ⚡ Built with React functional components and Hooks

## 🛠️ Technologies Used

- **React.js**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **Vite**
- **Local Storage API**
